🚗 Cloud-Based Vehicle Rental System

A modern, responsive, cloud-ready **Vehicle Rental System** developed using **HTML5, CSS3, Bootstrap 5, and JavaScript**. This project demonstrates an online vehicle rental platform where users can browse vehicles, register, book rentals, and manage bookings through an intuitive interface

📌 Project Overview

The Cloud-Based Vehicle Rental System is designed to simplify vehicle rental services through a user-friendly web application. It provides separate dashboards for customers and administrators while supporting cloud deployment concepts for scalability and availability.
